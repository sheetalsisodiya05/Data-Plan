# E-commerce Sales Pipeline

## Pipeline Lifecycle

1. Source:
   PostgreSQL stores customer orders and payments.

2. Ingestion:
   Collect new order data from PostgreSQL.

3. Transformation:
   Clean data and calculate revenue by country.

4. Storage:
   Store processed data in a data warehouse.

5. Serving:
   Display sales reports in Power BI.

## Five Undercurrents

1. Security:
   Protect customer and payment information.

2. Data Management:
   Maintain data quality and consistency.

3. DataOps:
   Monitor pipeline execution and detect failures.

4. Orchestration:
   Schedule and manage pipeline tasks.

5. Software Engineering:
   Write reusable, maintainable and tested code.
